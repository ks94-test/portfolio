# Karthikeyan S — Portfolio

A responsive, interactive portfolio website built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Project files

- `index.html` — page content and structure
- `styles.css` — responsive layout, visual design, and animations
- `app.js` — page interactions, guide, voice features, and dialogs
- `assets/karthikeyan-portrait.png` — portfolio portrait
- `assets/Karthikeyan_S_Resume.docx` — downloadable résumé
